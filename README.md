## Fluxo de desenvolvimento

Como organizo um projeto do zero até o deploy:

```mermaid
flowchart TD
    A([💡 Ideia]) --> B[Definir escopo\ne requisitos]
    B --> C[Criar repositório\ne estrutura base]
    C --> D{Tipo de projeto?}

    D -- Web App --> E[Flask ou Next.js\ncomo base]
    D -- Script / CLI --> F[Python puro\nou com libs]
    D -- API REST --> G[Flask + Blueprints\n+ Autenticação JWT]

    E --> H[Front: HTML/CSS/JS\nou Tailwind]
    F --> H
    G --> H

    H --> I[Integração com\nMySQL ou PostgreSQL]
    I --> J[Testes manuais\ne validação]
    J --> K{Pronto para subir?}

    K -- Não --> L[Ajustes e\nrefatoração]
    L --> J

    K -- Sim --> M[Git commit\nbem descrito]
    M --> N[Push para GitHub\ncom README]
    N --> O([✅ Deploy / Entrega])

    style A fill:#0b1120,color:#fff,stroke:#30363d
    style O fill:#0b1120,color:#fff,stroke:#30363d
    style D fill:#161b22,color:#ccc,stroke:#30363d
    style K fill:#161b22,color:#ccc,stroke:#30363d
```
